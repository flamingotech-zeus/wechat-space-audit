# 微信空间体检与安全清理

[English](README.md) | [简体中文](README.zh-CN.md)

> 盘点 Windows 上微信占用的空间，区分「可安全删的缓存」与「不能碰的数据」，产出先给你勾选的清理确认清单。

## 这是什么

这不是那种删完再报"释放了多少空间"的清理工具。那种设计有一个缺点，大到盖过它所有的好处：它偶尔会把你收到的某份文件一起删掉，而你是几周之后才知道。

这里的顺序是故意倒过来的。先扫描、出清单、等你确认、再动手。第一轮绝不删任何东西，不管需求怎么提的。

## 为什么开源

遇到这个问题的过程很普通 —— 笔记本没空间了，微信目录大得可疑，而里面几十个子目录哪个能删完全没数。靠猜不行，全删更不行。

它就是一个通用的维护工具，里面没有我们的东西，拿出来开源很干净。

## 能做什么

- **一份真实的目录地图。** 微信数据目录下每个文件夹到底装什么、量级大概多少，而不是笼统一句"缓存"。
- **分档清理策略。** 哪一类删了没事、哪一类删了会丢聊天记录、哪一类装的是收到的文件（删了就下载不回来）。
- **进回收站，不是删除。** 用 `SHFileOperationW` 送进系统回收站，删错了能捞回来。
- **核验这一步。** 移完之后检查回收站里的 `$I` 元数据文件，确认操作真的发生了。
- **一张勾选表。** 交付物是一张带"是否执行"列的表格让你勾，而不是一份"已经做了什么"的日志。
- **一条写明的死路。** 微信驻留托盘，没法用脚本优雅退出。试过、没成，两个都记下来了，省得别人再撞一次。

## 环境要求

Windows · Python 3

## 安装

```bash
git clone https://github.com/<你的用户名>/wechat-space-audit.git
```

然后把整个目录放进技能目录：

| 系统 | 路径 |
|---|---|
| Windows | `C:\Users\<你>\.workbuddy\skills\wechat-space-audit\` |
| macOS / Linux | `~/.workbuddy/skills/wechat-space-audit/` |

没有构建步骤，重启对话即生效。

## 怎么用

常见说法：

- "微信占了多大空间"
- "微信里有什么能安全删的"
- "清理一下微信缓存，先给我看清单"

它会只读扫描，按类别报体积，然后给你一张勾选表。你不说执行，它不动。

## 注意与边界

1. **第一轮永远只读。** 哪怕需求里写的是"直接清理一下"。清单存在的意义就是：删错了一次，代价是少勾一个框，而不是少一个文件。
2. **收到的文件是最大的坑。** 微信会把别人发给你的文件存在自己的目录里，过了期就下载不回来。这一类单独标出来。
3. **微信会占着文件锁。** 看起来能删的目录可能正在被占用。工具会把这些路径报出来，而不是硬删过去。
4. **回收站有容量上限。** 大批量删除可能绕过回收站，取决于系统设置 —— 动手前先看一眼回收站配置。
